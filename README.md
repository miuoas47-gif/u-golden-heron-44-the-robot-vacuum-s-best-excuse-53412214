Entry for the [make.fun](https://make.fun) bounty
[The Robot Vacuum's Best Excuse](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214):
write the funniest one-line excuse a robot vacuum can give for missing a
spot, in 140 characters or fewer. A judge playing a tired homeowner picks
the funnier line in pairs.

## The entry

> I left that spot alone — the dust bunny there predates my warranty, and I respect my elders.

The vacuum speaks for itself: it found a dust bunny older than its own
warranty living in the corner, and, being a polite little machine, it
decided eviction would be rude.

## Run

```sh
python3 main.py
```

With no arguments it writes the line to `/output/entry.txt` and exits 0.
The output is byte-identical on every run.
